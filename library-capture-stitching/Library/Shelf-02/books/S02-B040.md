# Writing an End-to-End Bundle-to-Splat Orchestration Script

By the time you reach this book you already have two working pieces: a module that unpacks `bundle.zip` and its `manifest.json` into a COLMAP-shaped project directory (covered in "Building the Bundle Ingestion Module: manifest.json to a COLMAP Project"), and a training recipe that turns a COLMAP sparse model into a trained splat (covered in "Setting Up a gsplat Training Run from a COLMAP Sparse Model"). What's missing is the thing that chains them: one script that a solo operator, or a queue worker behind their capture app, can point at a zip and walk away from until a `.ply` or checkpoint comes out the other side.

This book writes that script. It is deliberately thin. Its job is sequencing and subprocess management, not reinventing COLMAP's reconstruction logic or gsplat's training loop. Each stage is a black box invoked with the right flags; the orchestrator's value is in getting the handoffs between stages right, catching the failure modes that stop a run cold, and leaving behind enough of a trail that a human can tell what happened without re-running everything.

## The three stages, and what crosses the seams

An end-to-end run is three subprocess-shaped stages:

1. **Ingest** — unzip `bundle.zip`, read `manifest.json`, lay out a COLMAP project directory (`images/`, `sparse/`, a `database.db` path).
2. **Reconstruct** — run COLMAP against that project directory to produce a sparse model.
3. **Train** — feed the sparse model and images into gsplat to produce a trained splat.

The seams matter more than the stages. Ingest hands Reconstruct a directory structure, not a Python object; COLMAP is invoked as a subprocess, so the contract is "these paths exist and contain what COLMAP expects." Reconstruct hands Train a `sparse/0` model on disk (`cameras.bin`, `images.bin`, `points3D.bin`, per "Output Format — COLMAP"), and Train's own book covers how it consumes that. This orchestrator's contract with both neighbors is entirely path-based: it does not need to know the internal shape of a manifest or the internal shape of a gsplat config, only where each stage reads from and writes to.

## Picking the COLMAP entry point

COLMAP exposes two ways to run the pipeline. `automatic_reconstructor` runs the whole sparse-plus-dense pipeline in one command from `--workspace_path` and `--image_path`, and lets you tune `--quality` (LOW/MEDIUM/HIGH/EXTREME), `--data_type` (INDIVIDUAL/VIDEO/INTERNET), `--feature` (SIFT or ALIKED), `--mapper` (INCREMENTAL/HIERARCHICAL/GLOBAL), and `--mesher` (per "Command-line Interface — COLMAP"). That is the right entry point for this orchestrator: one process, one exit code, no separate feature/match/map invocations to babysit. Dense reconstruction and meshing are irrelevant to a splat pipeline that only needs the sparse model, so the script explicitly skips those outputs downstream rather than asking COLMAP not to produce them.

For a walkthrough capture, `--data_type INDIVIDUAL` and `--mapper INCREMENTAL` are the defaults worth keeping: incremental mapping is COLMAP's most robust and best-tested path, registering one image at a time and triangulating as it goes ("Tutorial — COLMAP"; "What is the difference between incremental and global SfM in COLMAP?"). Global mapping trades that robustness for speed on very large collections, which is not the profile of a single-room-at-a-time walkthrough bundle.

## The script

```python
"""orchestrate.py — bundle.zip in, trained splat out."""
from __future__ import annotations

import argparse
import json
import shutil
import subprocess
import sys
import time
from dataclasses import dataclass
from pathlib import Path


class StageError(RuntimeError):
    def __init__(self, stage: str, returncode: int, log_path: Path):
        super().__init__(f"{stage} failed (exit {returncode}); see {log_path}")
        self.stage = stage
        self.returncode = returncode
        self.log_path = log_path


@dataclass
class RunPaths:
    root: Path

    @property
    def project(self) -> Path:
        return self.root / "project"

    @property
    def images(self) -> Path:
        return self.project / "images"

    @property
    def sparse(self) -> Path:
        return self.project / "sparse"

    @property
    def logs(self) -> Path:
        return self.root / "logs"

    @property
    def splat_out(self) -> Path:
        return self.root / "splat"


def run_stage(name: str, cmd: list[str], paths: RunPaths) -> None:
    paths.logs.mkdir(parents=True, exist_ok=True)
    log_path = paths.logs / f"{name}.log"
    started = time.monotonic()
    with log_path.open("w", encoding="utf-8") as log_file:
        log_file.write(f"$ {' '.join(cmd)}\n\n")
        log_file.flush()
        proc = subprocess.run(cmd, stdout=log_file, stderr=subprocess.STDOUT)
    elapsed = time.monotonic() - started
    with log_path.open("a", encoding="utf-8") as log_file:
        log_file.write(f"\n[exit={proc.returncode} elapsed={elapsed:.1f}s]\n")
    if proc.returncode != 0:
        raise StageError(name, proc.returncode, log_path)


def stage_ingest(bundle_zip: Path, paths: RunPaths) -> dict:
    from ingest import ingest_bundle  # from Shelf-02's ingestion module

    paths.project.mkdir(parents=True, exist_ok=True)
    manifest = ingest_bundle(bundle_zip, paths.project)
    return manifest


def stage_reconstruct(paths: RunPaths, quality: str = "HIGH") -> None:
    paths.sparse.mkdir(parents=True, exist_ok=True)
    cmd = [
        "colmap", "automatic_reconstructor",
        "--workspace_path", str(paths.project),
        "--image_path", str(paths.images),
        "--data_type", "INDIVIDUAL",
        "--quality", quality,
        "--mapper", "INCREMENTAL",
        "--dense", "0",
    ]
    run_stage("reconstruct", cmd, paths)
    check_registration(paths)


def check_registration(paths: RunPaths) -> None:
    sparse_models = sorted(paths.sparse.glob("*/points3D.bin"))
    if not sparse_models:
        raise RuntimeError(
            "reconstruct produced no sparse model; see logs/reconstruct.log"
        )
    if len(sparse_models) > 1:
        print(
            f"warning: COLMAP produced {len(sparse_models)} disconnected models "
            "instead of one; only the largest will be used for training",
            file=sys.stderr,
        )


def largest_model_dir(paths: RunPaths) -> Path:
    candidates = list(paths.sparse.glob("*/points3D.bin"))
    return max(candidates, key=lambda p: p.stat().st_size).parent


def stage_train(paths: RunPaths, model_dir: Path, max_steps: int) -> None:
    paths.splat_out.mkdir(parents=True, exist_ok=True)
    cmd = [
        "python", "-m", "gsplat_train",  # from Shelf-02's training-run module
        "--data-dir", str(paths.project),
        "--sparse-dir", str(model_dir),
        "--result-dir", str(paths.splat_out),
        "--max-steps", str(max_steps),
    ]
    run_stage("train", cmd, paths)


def orchestrate(bundle_zip: Path, out_dir: Path, quality: str, max_steps: int) -> Path:
    paths = RunPaths(root=out_dir)
    paths.root.mkdir(parents=True, exist_ok=True)

    manifest = stage_ingest(bundle_zip, paths)
    (paths.root / "manifest_used.json").write_text(json.dumps(manifest, indent=2))

    stage_reconstruct(paths, quality=quality)
    model_dir = largest_model_dir(paths)

    stage_train(paths, model_dir, max_steps=max_steps)

    return paths.splat_out


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("bundle_zip", type=Path)
    parser.add_argument("out_dir", type=Path)
    parser.add_argument("--quality", default="HIGH",
                         choices=["LOW", "MEDIUM", "HIGH", "EXTREME"])
    parser.add_argument("--max-steps", type=int, default=30000)
    args = parser.parse_args()

    try:
        splat_path = orchestrate(args.bundle_zip, args.out_dir, args.quality, args.max_steps)
    except StageError as exc:
        print(f"error: {exc}", file=sys.stderr)
        return 1
    except RuntimeError as exc:
        print(f"error: {exc}", file=sys.stderr)
        return 1

    print(f"done: {splat_path}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Why the script is shaped this way

**Every stage writes its own log file, and the caller checks exit codes rather than parsing stdout live.** COLMAP's incremental mapper writes lines like `Registering image #241 (230)` and `=> Image sees 3755 / 8696 points` to its console output ("COLMAP incremental mapper console log format"), which is useful for a human tailing the log but not something this orchestrator needs to parse to know whether the stage succeeded. Subprocess exit code plus "did the expected output file appear" is a more reliable success signal than scraping log text, and it is far less code. The deeper question of what to do when a stage fails, how many times to retry, and how to distinguish a transient failure from a structural one, is the entire subject of "Hardening the Pipeline: Retrying, Logging, and Failing Loud"; this script only lays the groundwork by making every stage's failure raise a typed, log-pointing exception instead of silently returning a bad exit code.

**Registration health is checked by counting sparse models, not by a percentage threshold.** COLMAP will produce more than one disconnected model if not every image ends up registered into a single connected reconstruction ("Tutorial — COLMAP"). The notes for this shelf are explicit that the "registration health score" percentages used elsewhere in casual discussion (a sub-60% warning band, a ~95% healthy band) are Orbit Capture product conventions, not numbers COLMAP itself defines or publishes; this script does not invent a threshold it can't source, and instead treats "more than one output model" as the concrete, verifiable signal that something in the walkthrough broke continuity, warns about it, and picks the largest model to carry forward. When registration fails outright, COLMAP's own documented remedies are denser matching or manually specifying the initial image pair ("Frequently Asked Questions — COLMAP"); this orchestrator does not attempt that itself, it surfaces the log and lets the operator or a hardening layer decide.

**`--dense 0` is passed to `automatic_reconstructor` because the splat pipeline never touches COLMAP's dense output.** Gaussian splat training starts from the sparse point cloud, not a dense reconstruction: the original 3D Gaussian Splatting method explicitly seeds its Gaussians from SfM points to avoid wasting representation on empty space, and gsplat inherits that same sparse-model starting point ("3D Gaussian Splatting for Real-Time Radiance Field Rendering"; "gsplat: An Open-Source Library for Gaussian Splatting"). Running COLMAP's dense stereo and meshing anyway would cost real wall-clock time for outputs nothing downstream reads.

**The ingest and train stages are imported as modules, not shelled out, while COLMAP is always a subprocess.** COLMAP has no stable importable Python entry point for the full `automatic_reconstructor` pipeline in the way `pycolmap` exposes lower-level scene classes ("pycolmap Python bindings"), so a subprocess call against the CLI binary is the direct, documented way to drive it. The ingestion module and the gsplat training entry point, by contrast, are both first-party code built earlier on this shelf and can be called in-process, which keeps their exceptions as normal Python exceptions instead of another layer of exit-code parsing.

**One gap worth stating plainly:** the notes backing this shelf found no single authoritative source that GLOMAP's global mapping mode is production-ready enough to prefer over incremental for a solo-operator's single-room-at-a-time bundle; the comparison ("What is the difference between incremental and global SfM in COLMAP?") describes global mapping as faster with comparable accuracy but more sensitive to good focal-length priors, without a specific recommendation for this capture profile. This script defaults to `INCREMENTAL` and leaves `--mapper` as an exposed choice rather than asserting incremental is definitively correct for every bundle size.

## Running it

```bash
python orchestrate.py bundle.zip ./runs/room-042 --quality HIGH --max-steps 30000
```

A successful run leaves `./runs/room-042/` holding `project/` (the COLMAP workspace, including `sparse/0/` with `cameras.bin`, `images.bin`, `points3D.bin`), `logs/reconstruct.log` and `logs/train.log`, and `splat/` with the trained result. A failed run leaves the same structure minus whatever stage didn't finish, plus a log file naming exactly which command produced which exit code. That is the whole contract this script exists to fulfill: predictable inputs, predictable outputs, and a paper trail when something in between them breaks.
